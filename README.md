# Backend Learning

Daily log of backend concepts — one folder per day, each with a working Express server.

Coming from 7 years of frontend (React/TypeScript). Writing this to build real mental models, not just follow tutorials.

## Progress

| Day | Topic |
|-----|-------|
| [Day 01](./day01-http-basics/) | HTTP Request/Response Cycle |
| [Day 02](./day02-http-methods/) | HTTP Methods & Validation |
| [Day 03](./day03-status-codes/) | Status Codes |
| [Day 04](./day04-cors/) | CORS & Request Headers |

## Structure

Each day has a `server.js` you can run with `node server.js`. Shared notes are in [NOTES.md](./NOTES.md).

## Setup

```bash
npm install
node dayXX-topic/server.js
```
